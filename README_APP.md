# 🗼 ハノイの塔 - 小学生向けWebアプリ

「ハノイの塔」は、世界中で楽しまれているパズルゲームです。このWebアプリは、小学生が楽しく学べるように作られました！

## 🎮 ゲームの特徴

✨ **ビジュアルが分かりやすい**
- カラフルなリングと棒で、視覚的に分かりやすく
- アニメーション付きで楽しい操作感

🎯 **難易度が選べる**
- **かんたん**: 3個のリング（最小7回で完成）
- **ふつう**: 4個のリング（最小15回で完成）
- **むずかしい**: 5個のリング（最小31回で完成）
- **超難しい**: 6個のリング（最小63回で完成）

📊 **学習効果**
- 移動回数をカウント
- 最小回数を表示
- 論理的思考力が自然に鍛えられる

💡 **ヒント機能**
- 難しくなったときはヒントボタンを押そう！

## 📋 ゲームルール

1. **リングを選ぶ**: 移動したいリングをクリック
2. **移動先を選ぶ**: 移動先の棒をクリック
3. **大切なルール**: 大きなリングの上に小さなリングは置けない！
4. **クリア目標**: すべてのリングを右の棒に移動させたらクリア！

## 🌍 ハノイの塔とは？

ハノイの塔は、18世紀にベトナムの数学者によって作られた有名なパズルです。

**物語**: 古いお寺には、3本の柱と64枚の金のディスクがあります。修行僧たちは毎日、この金のディスクを動かす修行をしています。すべてのディスクが別の柱に移されたときに、世界は終わるという言い伝えがあります。

**数学的な意味**:
- n個のディスクを移動させるのに必要な最小回数 = **2^n - 1回**
- 例：
  - 3個 = 7回
  - 4個 = 15回
  - 5個 = 31回
  - 64個 = 18,446,744,073,709,551,615回（何年かかる！）
